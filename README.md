<h1 style="text-align: justify;">Microsoft AB-900 Exam: Learn to Manage and Secure Copilot and AI Agents</h1>

<p style="text-align: justify;">Microsoft 365 is changing with the introduction of AI-powered features, Copilot, and custom agents. Organizations need administrators who understand how these technologies work and how to protect company information while using them.</p>

<p style="text-align: justify;">The Microsoft AB-900 exam, also known as Microsoft 365 Copilot and Agent Administration Fundamentals, is designed to test this knowledge. It is suitable for beginners interested in Microsoft 365 administration, AI productivity, security, and data governance.</p>

<p style="text-align: justify;">Microsoft Purview and data governance deserve extra attention because they represent the largest portion of the exam.</p>

<p style="text-align: justify;">You should understand Microsoft Entra ID, Conditional Access, SharePoint permissions, sensitivity labels, Data Loss Prevention (DLP), retention policies, and Microsoft Defender capabilities. Also learn how Copilot uses Microsoft Graph and existing user permissions to access organizational information.</p>

<h2 style="text-align: justify;">What Happens When Copilot Accesses Sensitive Company Data?</h2>

<p style="text-align: justify;">Consider a company where employees use Microsoft 365 Copilot to summarize documents and emails. An employee can access a confidential SharePoint document that should only be available to a specific department.</p>

<p style="text-align: justify;">The administrator needs to understand why the document is accessible and how to correct the permissions. Microsoft Purview, SharePoint access controls, and data governance features can help identify and reduce these risks.</p>

<p style="text-align: justify;">You should also understand how administrators assign Copilot licenses, monitor usage, manage billing policies, create agents, and control user access to those agents.</p>

<h2 style="text-align: justify;">How Can You Turn These Topics into Practical Knowledge?</h2>

<p style="text-align: justify;">Don&#39;t limit your preparation to reading product descriptions. Explore Microsoft 365 admin center, Microsoft Purview, and Microsoft Entra to understand where different administrative tasks are performed.</p>

<p style="text-align: justify;">For example, practice identifying which feature is suitable for protecting sensitive information, investigating suspicious user activity, or controlling access to an AI agent.</p>

<p style="text-align: justify;">This approach will help you understand the purpose of each service and make better decisions when answering scenario-based questions.</p>
